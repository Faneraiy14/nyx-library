# Бібліотека NyxOS

Тут житиме **Бібліотека NyxOS** — каталог програм і доповнень, які система встановлює сама: з термінала
(`lib install <назва>`), з програми «Бібліотека» на робочому столі або з сайту.

*The NyxOS Library: a signed catalog of apps and add-ons that NyxOS installs from the terminal, the desktop
"Library" app or the website.*

## Що тут буде

- **`.nyxapp`** — те, що запускаєш: програми й ігри.
- **`.nyxlib`** — те, що встановлюєш у систему для інших: бібліотеки, інструменти й команди, шрифти, кодеки,
  середовища сумісності.
- **Підписаний індекс** — список усього в Бібліотеці з контрольними сумами. Система встановлює лише те, що є в
  підписаному індексі, тож підмінити програму «оновленням» не вийде.

## Категорії

Основа · Розробка · Ігри · Мультимедіа · Мережа · Сумісність · Система й безпека · Мови й шрифти

## Довіра й підписи

1. **Офіційне** — підписане ключем NyxOS: ставиться без зайвих питань.
2. **Від автора** — підписане ключем розробника: при першому встановленні система показує автора й відбиток
   ключа; оновлення приймаються лише з тим самим ключем.
3. **Непідписане** — лише після попередження й явного підтвердження.

Кожне доповнення спершу перевіряє автор NyxOS.

## Стан

Формат і перші доповнення з'являться у версії **0.5 «Додатки»**. Програми для NyxOS уже можна писати —
